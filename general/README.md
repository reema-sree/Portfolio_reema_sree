# Reema Sree Harshini — General portfolio

A playful, hand-drawn-inspired personal portfolio for Reema Sree Harshini. Built with static HTML, CSS, and JavaScript, with responsive layouts and pointer-reactive motion.

## Local preview

Open `index.html` in a browser. Lenis and Google Fonts load from their public CDNs when online.

## Contact form setup

The form uses Web3Forms when configured. In `script.js`, replace `YOUR_WEB3FORMS_ACCESS_KEY` with the access key from your Web3Forms account. Until then, the form validates the fields and opens a prefilled email to Reema as a fallback.

## Booking link

Set `BOOKING_URL` in `script.js` to your Calendly or Cal.com personal booking URL. Until then, the button opens an email asking to schedule a call.

## Publish

The site is configured for static hosting on Vercel. `sitemap.xml`, `robots.txt`, `assets/favicon.svg`, and `assets/og-card.png` provide the sharing and indexing essentials.
